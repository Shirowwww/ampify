# Создавайте для Ampify

Тема — это папка с несколькими текстовыми файлами. Расширение — это один файл JavaScript (или TypeScript, его
скомпилируют за вас) и манифест. Нужны установленный Ampify, Apple Music и терминал, открытый в рабочей папке.
Ничего компилировать не надо, аккаунт заводить не нужно. Подробная документация написана по-английски.

1. **Начните с того, что уже работает.**
   `ampify new theme my-theme` (или `extension`, `snippet`, `app`) создаёт в текущей папке готовую заготовку.
   Она уже запускается: вы меняете то, что работает, а не начинаете с чистого листа.

2. **Смотрите вживую.**
   `ampify dev my-theme` копирует работу в Ampify, включает её и перезагружает при каждом сохранении. Apple Music
   меняется меньше чем за секунду, без перезапуска. Оставьте терминал открытым.

3. **Найдите, что оформлять.**
   Темы обращаются к постоянным именам зон Apple Music: `.sidebar`, `.playbar`, `.lcd`, `.track-row`, `.card` и ещё
   больше сотни других ([полный список](../themes/names.md)). Для всего остального `ampify devtools`, а затем
   `ampify inspect` покажут живое дерево интерфейса с селектором каждого элемента.

4. **Придайте форму.**
   Цвета лежат в `colors.ini`, по одному разделу на цветовую схему. Формы, отступы, эффекты при наведении, переходы
   и анимации лежат в `user.css`, на привычном вам CSS. Тема может объявить собственные настройки (ползунок,
   переключатель, выбор), которые каждый меняет в настройках Apple Music. См. [формат темы](../themes/format.md).

5. **Или напишите поведение.**
   Расширения используют API `Ampify`: плеер, трек, уведомления, меню, панели, хранилище и запросы в сеть,
   которые объявлены в манифесте. Каждое разрешение показывается людям до установки. См.
   [руководство по расширениям](../extensions/guide.md) и [API](../extensions/api.md).

6. **Проверьте.**
   `ampify validate my-theme` проверяет манифест и файлы по тем же правилам, что и каталог.

7. **Поделитесь.**
   `ampify publish my-theme` проверяет работу ещё раз, затем сам открывает pull request в
   [публичном каталоге](https://github.com/Shirowwww/ampify-catalog), ничего не клонируя. После принятия работа
   появится в Marketplace у каждого Ampify и в [галерее](themes.html). Весь путь, вместе с предпросмотром, описан в
   [пяти шагах](../extensions/catalog.md#propose-an-element-in-five-steps).
{: .steps}

## Один способ для каждой задачи

Темы, сниппеты и расширения пользуются общими инструментами. Если два вида элементов умеют одно и то же, они делают
это одинаково, поэтому то, что вы узнали для одного, работает и для других.

| Чтобы... | Используйте | Где работает |
|---|---|---|
| Предложить настройки | Поле `settings` манифеста ([манифест](../extensions/manifest.md#settings)): CSS читает их через `@setting` и `--setting-<key>`, JavaScript через `Ampify.config.get(key)` | Темы, сниппеты, расширения, приложения |
| Перевести название, описание и настройки | Поле `translations` манифеста | Все элементы |
| Узнать, где панель воспроизведения | `@setting bar-position`, его выбирает пользователь для всех тем, или `"playbar"` темы | Темы, сниппеты |
| Следовать скруглению панелей | `--panel-radius` (а также `--bar-radius` и `--lcd-radius` для панели и дисплея) | Задают темы и сниппеты; сниппеты и панели расширений следуют за ним |
| Взять цвета играющей обложки | `--art-1` — `--art-3` и родственные в CSS, `Ampify.color.playing()` в JavaScript | Все |
| Нарисовать полосы, движущиеся в такт музыке | `content: bars(n, shape, height)` | Темы, сниппеты |
| Размыть, перекрасить или сделать стеклянным любой элемент | `filter` и `backdrop` | Темы, сниппеты |
| Оформить строку, переключатель или элемент управления по его состоянию | `:hover`, `:active`, `:focus`, `:current`, `:playing`, `:checked`, `:selected`, `:disabled` | Темы, сниппеты |
| Отметить отрезок линии прогресса | `Ampify.ui.playbar.mark(id, from, to)` | Расширения |
| Собрать интерфейс | Узлы `Ampify.ui` или `Ampify.React` с `Ampify.components` (кнопки, переключатели, флажки, ползунки, поля, меню, вкладки, индикаторы прогресса, индикаторы загрузки, разделители...) | Расширения, приложения |

В [формате темы](../themes/format.md#what-a-theme-tells-snippets-and-extensions) перечислено, что тема передаёт
другим элементам, а в [API](../extensions/api.md#55-interface-stable) — каждый узел и компонент.

## Если вы пришли из Spicetify

Файл `color.ini` из Spicetify работает как есть: положите его в папку темы, и его цвета оденут Apple Music. В
`user.css` вместо классов Spotify нужны имена Ampify. [Что переносится, а что нет](../themes/spicetify.md).

## Лицензии

Ampify распространяется по лицензии PolyForm Noncommercial 1.0.0: бесплатно для любого использования, кроме
коммерческого, с сохранением авторства. Эта лицензия не распространяется на то, что вы создаёте: темы, сниппеты,
расширения и приложения, которые используют только документированные форматы и API Ampify, принадлежат вам, под любой
лицензией на ваш выбор, коммерческой или нет. Заготовки, созданные `ampify new`, и примеры распространяются по
лицензии MIT, так что копируйте из них свободно.
